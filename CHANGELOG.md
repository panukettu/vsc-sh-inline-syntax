# Change Log

All notable changes to the "sh-inline-syntax" extension will be documented in this file.

## [0.1.0]

- Initial release
- Inject awk / gawk / mawk / nawk, jq, `python -c`, sed, jp / jpx, and `--query` / `--jq` highlighting into `source.shell`
- Standalone JMESPath (`.jp` / `.jpx`) and sed (`.sed`) language grammars
